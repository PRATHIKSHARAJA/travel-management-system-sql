# Travel Management System | SQL Database Project

## Project Overview

A relational database project designed to organize travel-related information, including customers, destinations, packages, bookings, payments, and employees.

## Objectives

* Design and query a relational database.
* Retrieve booking and customer information.
* Analyze revenue and monthly income.
* Identify popular travel packages.
* Examine cancelled bookings.
* Practice SQL queries for business reporting.

## Database Tables
